# AI-Based Dynamic Factory Production Scheduling

## Research Project

AI-Based Dynamic Factory Production Scheduling Using
Reinforcement Learning: A Simulation-Based Approach
with PPO and Classical Dispatching Rules.

## Research Objective

This project investigates reinforcement learning-based
decision-making for dynamic job-shop production scheduling.

The proposed system uses Proximal Policy Optimization (PPO)
to make production scheduling decisions under dynamic
manufacturing conditions.

## Technology Stack

- Python 3.11
- SimPy
- Gymnasium
- Stable-Baselines3
- SB3-Contrib (MaskablePPO)
- NumPy
- Pandas
- Matplotlib
- TensorBoard
- Unity 6

## Scheduling Algorithms

- PPO / MaskablePPO
- FIFO (First In, First Out)
- EDD (Earliest Due Date)
- SPT (Shortest Processing Time)

## Research Scenarios

- Dynamic job arrivals
- Machine breakdowns
- Processing time uncertainty
- Sequence-dependent setup times
- Different workload levels
- Different due-date tightness levels

## Evaluation Metrics

- Mean tardiness
- Total tardiness
- Makespan
- Average flow time
- Machine utilization
- On-time delivery rate

## Project Architecture

- factory_sim/: Discrete-event factory simulation
- rl_env/: Reinforcement learning environment
- agents/: PPO agent and training
- baselines/: Classical scheduling algorithms
- experiments/: Benchmarking and ablation studies
- configs/: Experimental configurations
- tests/: Automated tests
- datasets/: Experimental datasets
- models/: Trained models
- results/: Experimental results
- logs/: Training logs
- unity-client/: Unity visualization

## Reproducibility

Python dependencies are recorded in requirements.txt.

All experiments will use controlled random seeds
and documented configuration files.
